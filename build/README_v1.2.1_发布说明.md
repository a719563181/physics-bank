# v1.2.1 发布说明

发布日期：2026-10-23

## 一句话

Word 导入的「答案解析被当成题干」问题彻底修好，并把导入改成能真正干活的界面。

---

## 一、修了什么

### 1. 答案解析不再污染题目（严重）

旧版把 Word 卷里的答案当成正文：

- 答案紧跟选项 → 拼进选项 D，`D. 20 m/s【答案】B【解析】…`
- 末尾集中答案区 → 每行答案变成一道**伪题**，题干内容是「答案：C」

真实卷（高三物理十月月考 A 卷）实测：

| | 修复前 | 修复后 |
|---|---|---|
| 题目 | 8 真 + **7 伪** | **8** |
| 答案归位 | 0 / 8 | **8 / 8** |

### 2. 答案根本没进库（严重）

上一版虽然能分离答案，但入库时写死 `answer=''`，实际一道都没保存。

现在答案和解析真正写入题库。

### 3. 难度改不了

`QFormLayout` 建了却从未 `addRow`，难度控件被当成「来源名」的标签吞掉，点击无反应。已修复。

### 4. 切换题目丢改动

改了题干不保存就点另一题，改动无声消失。现在会问「保存 / 丢弃 / 取消」。

---

## 二、加了什么

- **解析输入框**：分离出的解析原来在内存里没有出口
- **配图缩略图**：Word 抽出的图能直接看见，点开看大图
- **保存后自动跳下一题**：最后一题给提示
- **列表行显示答案**：`[3] 单选题 ✓B`，哪题有答案一眼可见
- **导入前自检**：状态栏显示「已勾选 8 题，1 题无答案」，确认框列出具体风险
- **原始文本对照**：Word 导入也能看到原始段落（原来只有 OCR 有）

---

## 三、验证

- 单元测试 `tests/test_answer_split.py`（8 组 40+ 用例）、`tests/test_ocr_enhance.py` 全过
- 端到端：Word → 界面编辑 → 导入 → 查库，4/4 带答案、4/4 带解析
- 真实卷：8 题、7 题带答案（第 4 题为纯公式题，本无答案）、0 伪题
- 安装包静默安装 + GUI 启动 + 隔离库建库，全部通过
- 安装副本与源码 MD5 逐字节一致

## 四、安装

1. 运行 `高中物理题库管理_安装包_v1.2.1.exe`
2. OCR 功能需要离线引擎包：把 `PhysicsBank_OCR引擎包_v1.2.0.7z`
   解压到程序安装目录旁的 `runtime-ocr` 文件夹

**引擎包无需重新下载** —— 本版改动全在主程序。

---

## 五、已知限制

- Word 里放在**纯文本框且无正文段落**的内容，解析能力有限
- 竖排分式在没有视觉模型时可能留下碎片，程序选择保留而不是猜错
- `.doc`（旧格式）需先另存为 `.docx`
