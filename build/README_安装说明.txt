========================================================
  高中物理题库管理（离线版） v1.0.0  安装说明
========================================================

【这是什么】
  一款在 Windows 上离线运行的高中物理题库管理软件。
  不联网、不上传，所有题目和数据都只存在你自己的电脑上。

【主要功能】
  · 题目录入：支持题干、答案、解析、配图，题干里可直接写 LaTeX 公式
  · 公式速编：常用符号一键插入 + 实时预览 + 自定义公式库
  · 题型：单选题 / 多选题 / 填空题 / 判断题 / 实验题 / 计算题
  · 知识点：可自定义增删改，按知识点筛选
  · 查重：录入时自动检索相似题，避免重复
  · 批量导入：Excel / CSV 表格导入
  · 组卷：从题库选题、排序、设定分值
  · 导出：Word（教师版 / 学生版）、PDF、PPT 讲义
  · PPT 模板：可自定义配色和版式，公式墨色自动跟随主题
  · 题库导出 / 导入：打成一个 .pbk 文件，拷到别的电脑直接用

【换电脑 / 迁移题库】
  1. 在旧电脑：菜单 [工具 → 题库导出 / 导入] → 「导出题库」
     得到一个 .pbk 文件（题目 + 知识点 + 试卷 + 配图 + 公式库 + 模板）
  2. 把 .pbk 拷到新电脑（U 盘 / 网盘 / 微信都行）
  3. 在新电脑：菜单 [工具 → 题库导出 / 导入] → 「导入题库」
     选「合并进来」保留新电脑已有题目，或「清空后导入」只留包里的

  导入时知识点按名称自动匹配（同名不重复建），公式库和模板按内容去重。

【系统要求】
  · Windows 10 / 11（64 位）
  · 导出 PDF 需要本机安装 Microsoft Word 或 LibreOffice（免费）
    —— 只导出 Word / PPT 的话不需要
  · 本版为「精简版」，不含扫描件 OCR 识别

【首次启动】
  第一次打开需要几秒（要初始化数据库），请耐心等待。
  启动后即可开始录入题目。

【数据存在哪】
  你的题库数据保存在：
      %LOCALAPPDATA%\PhysicsBank\
  里面有：
      data\bank.db          题库数据库
      data\attachments\     题目配图
      data\formula_cache\   公式图片缓存
      exports\              导出的文件
      themes\               自定义 PPT 模板

  ★ 重要：备份题库只需复制 data\bank.db 这一个文件。
    软件不会自动删除你的数据，卸载软件也会保留这些数据。

  ★ 想看当前数据到底在哪：菜单 [工具 → 数据位置...] 会直接告诉你，
    并能一键打开那个文件夹。

【便携模式（可选）】
  如果你希望数据跟着程序走（比如放 U 盘），
  在程序目录旁建一个 data 文件夹，把 bank.db 放进去，
  软件就会优先用那个位置。
  也可以用环境变量 PHYSICS_BANK_HOME 指定任意目录。

【常见问题】

  Q: 点「OCR 批量导入」提示未包含 OCR？
  A: 本版是精简版，OCR 需要约 4GB 的额外引擎，未包含在内。
     请改用「Excel/CSV 批量导入」，或手工录入。
     需要 OCR 可以单独获取完整版。

  Q: 导出 PDF 报错？
  A: 需要本机安装 Word 或 LibreOffice。没装的话，
     可以先导出 Word 再用其他工具转 PDF。

  Q: 想换个地方存数据？
  A: 两种办法：
     ① 在程序目录旁建 data 文件夹放进 bank.db（便携模式），或
     ② 设置环境变量 PHYSICS_BANK_HOME 指向你要的目录。
     想知道当前用的哪个目录，看 [工具 → 数据位置...]。

  Q: 换了台电脑，题目怎么搬过去？
  A: 菜单 [工具 → 题库导出 / 导入] → 导出题库，把生成的 .pbk
     文件拷到新电脑，再用「导入题库」导入即可。

  Q: 软件打不开 / 闪退？
  A: 查看 %LOCALAPPDATA%\PhysicsBank\crash.log，里面有详细错误。

【卸载】
  开始菜单里点「卸载 高中物理题库管理」，
  或在「设置 → 应用」里找到它卸载。
  卸载不会删除你的题库数据。
